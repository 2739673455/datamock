# Git LFS
仓库中的 `.doc`、`.docx` 和 `.pdf` 文件使用 Git LFS 管理。首次克隆前安装并初始化 Git LFS：

```bash
git lfs install
git clone https://github.com/2739673455/datamock.git
```

已经克隆仓库但缺少实际文档内容时执行：

```bash
git lfs pull
```
